# Retail Data Engineering Pipeline

## Overview
A retail data engineering project built with Databricks and PySpark to process retail transaction data from Kaggle into structured, analytics-ready datasets.

## Data Source
[Kaggle – Retail Transaction Dataset](https://www.kaggle.com/datasets/fahadrehman07/retail-transaction-dataset)

## Tech Stack
- Python
- PySpark
- Databricks
- Delta Lake
- Git & GitHub

## Architecture
- **Bronze:** Raw data ingestion
- **Silver:** Data cleaning and validation
- **Gold:** Data transformation for analytics

## Project Goals
- Build an end-to-end data pipeline.
- Implement data quality checks.
- Support incremental and idempotent data processing.
- Practice data engineering workflows using Databricks and GitHub.
